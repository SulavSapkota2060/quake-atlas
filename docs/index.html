Aftershocks after the biggest quakes

Take these counts as a rough guide. The 110 km box can miss aftershocks along a long rupture, and I only count M4.5 and up, so small aftershocks right after a big quake are probably missing. Nearby quakes also share aftershocks, so don't add the rows up.

Data: USGS Earthquake Catalog (ComCat), magnitude 4+ inside 24–37°N, 70–98°E. Page data generated –.

This page describes what has already happened. It can't predict earthquakes. The catalog mixes several magnitude scales, and it probably misses more small quakes in the early years than in recent ones.
